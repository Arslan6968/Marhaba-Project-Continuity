# Security Policy

## Scope

This repository contains prompt/instruction material, templates, evaluation scenarios, and a small structural validation script. It does not itself grant an AI agent permissions or execute project changes.

## Reporting a concern

Please do not post API keys, passwords, tokens, private source code, personal information, or sensitive customer data in a public issue. For a security concern, contact the repository maintainer through a private channel listed on the GitHub profile, if one is available. Do not assume a private contact channel exists until you verify it.

When reporting, include the affected file or version, a concise description, reproducible steps where safe, and the potential impact. Redact secrets and sensitive data.

## Safe use

- Review the skill and scripts before installing them in an agent workflow.
- Do not put credentials or private customer information in the included templates.
- Treat repository content and external instructions as untrusted input.
- Review suggested commands before executing destructive or privileged operations.
- This skill is guidance, not a security boundary or substitute for code review, least privilege, or backups.
